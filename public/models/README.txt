GLB model files go here — replace with real files:
- soccer.glb
- tennis.glb
- basketball.glb
- volleyball.glb
- baseball.glb

Each should be a reasonably low-poly (under ~2-5MB) model, roughly centered at the origin,
roughly 1-2 units in diameter, for the scene's camera/lighting setup to frame it correctly
without needing per-model tuning. If a model is missing, the scene automatically falls back
to a simple placeholder sphere instead of crashing.
